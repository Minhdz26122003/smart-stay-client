# Authentication & Core UI Implementation Plan

> **For Antigravity:** REQUIRED WORKFLOW: Use `.agent/workflows/execute-plan.md` to execute this plan in single-flow mode.

**Goal:** Implement shared UI components, Mock Authentication API, standard Auth BLoC, and the Login Page based on the Harmonious Host design system.

**Architecture:** 
- `core/widgets`: Centralized custom UI widgets (Buttons, Inputs).
- `features/auth/domain`: `User` entity and `AuthRepository` interface.
- `features/auth/data`: `MockAuthRepositoryImpl` that mimics network calls.
- `features/auth/presentation`: `AuthBloc` (events/states) and `LoginPage` UI.

**Tech Stack:** Flutter, flutter_bloc, freezed, mocktail, get_it
